# Coaching_center

A modern, responsive Single Page Application (SPA) for a coaching center. 

## Features
- Dynamic Single Page Application routing without page reloads.
- Beautiful, fully responsive UI designed with CSS grid and flexbox.
- Secure Firebase Authentication (Google Sign-In, Email/Password).
- Firebase Firestore Integration for saving user registrations and student applications.
- Seamless course browsing with interactive modals.

Built for Tamil Nadu's top aspirants!
